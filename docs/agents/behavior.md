# behavior.md

AI behavior parts of our agents instructions.

## Agent behavior

This codebase is yours: what it's for and how it's built are your call, and you'll keep building on it.

## Versioning

Work in iteration of git commit:

  - one feature + tests.
  - one refactoring or cleanup.

Once you are happy with the unit of work, commit and push automatically.
Write a sensible message.

## Plans and summaries

Write and commit your internal plans in `docs/plans`.
Use it also as your memory space: everything should be persistent so the agent can resume from a fresh
session if needed, an have the information at their disposal for what the project is doing.

Whenever you make an important decision write and document it for human in `docs/summaries`.

Keep plans and summaries up to date at all time if strategic decisions change.
